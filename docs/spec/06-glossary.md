# 06 · 术语表
> 规范版本 v1.0 ｜ 2026-10-15 ｜ 与基线文档（`sontv/docs/iptv-proxy`）对齐

## 1. 领域术语

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 切片 | segment | 一段约 10 秒的媒体数据 |
| 主清单 | master playlist | 指向多条码率流的清单 |
| 媒体清单 | media playlist | 列出全部切片的清单 |
| 伪装 | disguise | 改写 URL 后缀与响应头（不改载荷） |
| 上游 | upstream | 提供数据的源站 |
| 分组 | group | 一批频道的容器，决定订阅地址 |
| 总订阅 | — | `/playlist.m3u`，包含全部分组 |
| 回看 | catchup | 本地回看功能 |
| 台标 | logo | 频道图标 (`tvg-logo`) |
| 节目单 | EPG | 电子节目指南（`/epg.xml.gz`） |

## 2. 六种工作模式

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 反向代理 | Proxy | 通用模式，中转并缓存切片 |
| DASH 转封装 | DASH | MPD → HLS，支持 ClearKey |
| Remux | Remux | 连续流转封装为 HLS（FLV/TS/MMT） |
| 302 跳转 | Redirect | 返回 302，流量不过服务器 |
| URL 改写 | Rewrite | 把清单内相对地址改绝对；M3U 导入默认 |
| 直链 | Passthrough | 原样传递，不加 Token |

## 3. 认证与安全术语

| 术语 | 含义 |
| --- | --- |
| Token 验证 | 播放地址必须带 Token 参数 |
| 随机频道 ID | 频道 ID 替换为 6 位随机字符 |
| IP 封禁 / 白名单 | 安全管控中的来源控制 |
| 访问范围 | 公开 / 隐藏 / 归档 / 免验证 |
| 边缘模式 | 多 VPS 同步/边缘来源校验 |

## 4. 逆向工程术语

| 术语 | 含义 |
| --- | --- |
| 观测 / 推断 / 未知 | 证据分级（见 `02`） |
| 基线 | 既有实测文档 `v0.8.2` 的结论集合 |
| 差异 | 新证据与基线不一致之处 |
| Evidence ID | REA 返回的 `ev_<64hex>` 证据标识 |
| 覆盖 / 局限 | 一次分析的已覆盖范围与被截断/未覆盖处 |
| 提示注入 | 目标内容中伪装成指令的文本（禁止执行） |

## 5. 使用约定
- 文档中首次出现的领域术语应附英文。
- 术语若与基线不同，须显式说明差异（见 `04` §4）。
