## 3. 差异登记

出现 `⚠️ 差异` 时，在 `docs/findings/` 下建独立小节，包含：

1. 基线的原文结论与出处；
2. 本次证据（命令 / Evidence ID / 环境）；
3. 差异范围（是否版本差异、架构差异、环境差异）；
4. 处置（更新基线建议 / 待复测 / 已澄清）。
