# 15 · 订阅源质量准入功能设计

> 阶段：功能设计。依据 [`14-quality-admission-product.md`](14-quality-admission-product.md)。
> 本文定义页面、流程、状态与交互。接口、表结构、并发与调度实现留到系统设计。

## 1 设计原则

- 页面只展示可解释的结果。每个移出动作必须有原因。
- 破坏性动作必须确认。源删除、源停用移出、批量校验移出都要二次确认。
- 保存与运行分离。规则先保存，再运行。运行使用已保存规则。
- 所有质量入口集中到「质量校验」页。系统设置不再重复放规则字段。
- 管理端专用。普通用户看不到质量页。

## 2 信息架构

侧栏新增一级入口：

```
我的订阅
概览
缓存状态
分组管理
质量校验        ← 新增，activity 图标，管理员可见
系统设置
...
```

质量页内部使用四个标签：

| 标签 | 内容 |
| --- | --- |
| 概览 | 状态、最近任务、统计、立即校验 |
| 规则 | 全局规则、周期、安全阀、覆盖规则 |
| 结果 | 准入与移出的频道结果、筛选、详情 |
| 来源 | 同步源门控状态、同步与停用/删除入口 |

默认打开「概览」。从分组页质量徽章进入时，打开「结果」并按 `gid/cid` 过滤。

页面状态保存在地址哈希中，例如：

```
#/quality
#/quality/results?gid=sports&cid=c1
```

返回、刷新、复制链接都应恢复同一个标签与筛选。

## 3 通用交互

### 3.1 加载与错误

- 首屏显示骨架或「读取中…」。
- 读取失败显示错误卡与「重试」。
- 401 按现有逻辑回到登录。
- 403 不显示入口；直接访问返回无权限提示。

### 3.2 保存冲突

规则保存带配置 `revision`。冲突时：

```
配置已被其他页面修改。
[重新加载]  [取消]
```

重新加载会覆盖当前未保存修改。取消保留草稿，但不能保存，直到重新加载。

### 3.3 运行中

- 运行中禁用「立即校验全部」，显示「校验中…」与「取消」。
- 进度每 2 秒刷新。
- 取消后显示「取消中…」，已完成的结果保留，未开始的频道跳过。
- 取消不回滚已经执行的移出。

### 3.4 确认对话框

统一结构：标题、影响说明、主按钮、取消按钮。破坏性主按钮使用危险样式。

## 4 概览

### 4.1 布局

```
质量校验                                    [立即校验全部] [取消]

┌ 状态 ─────────────────────────────────────────────┐
│ 已启用 · 每 6 小时 · 下次 18:00                     │
│ 最近任务：12:00 完成，耗时 2m10s，下载 58 MB         │
│ 准入 118 · 移出 6 · 探测错误 2                      │
└──────────────────────────────────────────────────┘

┌ 统计 ────────────────┐ ┌ 警告 ────────────────────┐
│ 已准入 118            │ │ 源 A 抓取失败，成员未变     │
│ 7 天内移出 23         │ │ 安全阀已暂停上一轮成员变更  │
│ 同步源 4              │ │                           │
└──────────────────────┘ └───────────────────────────┘

┌ 最近任务 ─────────────────────────────────────────┐
│ [████████░░] 140 / 150   阶段：质量校验            │
│ 动作：移出 6 · 准入 12 · 保留 122                  │
└──────────────────────────────────────────────────┘
```

### 4.2 状态卡

显示：

- 总开关状态。
- 周期模式与下一次运行时间。
- 最近任务时间、结果、耗时、下载量。
- 准入数、移出数、探测错误数。

点击「周期」跳到规则标签。

### 4.3 立即校验全部

点击后弹确认：

启用时：

```
按当前规则校验全部已准入频道。
不合格频道会立即移出分组。
[开始校验] [取消]
```

停用时：

```
质量校验已停用。
本次只测量并记录，不改变分组。
[仅测量] [取消]
```

运行中再次点击显示「已有校验任务在运行」。

### 4.4 警告

按严重度排序：

- 安全阀触发：红色，显示阈值与本轮将移出数，提供「查看结果」「打开规则」。
- 源抓取失败：黄色，显示源名与错误。
- `probe_error` 数量异常：黄色，提示检查解析器或探测地址。
- 规则已保存但尚未运行：蓝色，提供「立即校验」。

## 5 规则

### 5.1 布局

规则页分四块：

1. 运行参数。
2. 判定阈值与失败处理。
3. 安全阀。
4. 周期。

底部固定保存栏：

```
[未保存 3 项]                         [重新读取] [保存规则]
```

### 5.2 运行参数

| 字段 | 控件 | 说明 |
| --- | --- | --- |
| 质量校验 | 开关 | 关闭后不改变成员。手动校验只测量。 |
| 探测档位 | 下拉：连通 / 清单 / 测速 / 完整 | 完整在 P1 按测速执行。 |
| 超时 | 数字，秒 | 单次请求超时。 |
| 测速超时 | 数字，秒 | 单次切片或连续流超时。 |
| 并发 | 数字 | 1–32。 |
| 单轮流量预算 | 数字，MB | 0 = 不限制。 |
| 单轮频道上限 | 数字 | 0 = 不限制。 |
| 同步门控时限 | 数字，秒 | 默认 300。0 = 不限制。 |

### 5.3 判定阈值与失败处理

| 字段 | 控件 | 说明 |
| --- | --- | --- |
| 最低速率 | 数字，MiB/s | 0 = 不限制。 |
| 最大延迟 | 数字，毫秒 | 0 = 不限制。 |
| 最低分辨率 | 文本，`WxH` | 留空不限制。 |
| 最高分辨率 | 文本，`WxH` | 留空不限制。 |
| 同步源失败处理 | 只读：移出分组 | 产品固定。 |
| 手工频道默认处理 | 下拉：保留 / 下线 | 默认保留。 |

说明文案：

> 同步源频道不合格时立即移出分组。手工频道默认保留；选择下线时只从订阅隐藏。

### 5.4 安全阀

| 字段 | 控件 | 默认 |
| --- | --- | --- |
| 启用安全阀 | 开关 | 开 |
| 最大移出比例 | 数字，百分比 | 50% |
| 最小移出数量 | 数字 | 10 |

提示：

> 只有同时达到比例与数量才触发。触发后本轮不改变成员。

### 5.5 周期

```
周期模式： (•) 按小时   ( ) cron
间隔：    [ 6 ] 小时
```

或：

```
周期模式： ( ) 按小时   (•) cron
表达式：  [ 0 */6 * * * ]
下次运行：今天 18:00、明天 00:00、明天 06:00
```

规则：

- 按小时：最小 1，最大 8760。
- cron：5 段，按服务器时区。
- 表达式错误时保存按钮禁用，字段下方显示错误。
- 切换模式保留另一模式的值，不互相覆盖。

### 5.6 覆盖规则

覆盖表列出：

| 范围 | 名称 | 启用 | 失败处理 | 阈值摘要 | 来源 |
| --- | --- | --- | --- | --- | --- |
| 源 | 源 A | 继承 | 移出 | 最低 2 MiB/s | 源 |
| 分组 | 体育 | 启用 | 移出 | 最低 4 MiB/s | 分组 |
| 频道 | CCTV-5 | 继承 | 移出 | 继承 | 频道 |

交互：

- 「新建覆盖」先选范围与对象。
- 抽屉内每个字段有「继承」开关。开启时显示继承值与来源。
- 「恢复全局」清除该对象全部覆盖。
- 保存仍走配置 `revision`。
- 同一字段按频道 > 分组 > 源 > 全局解析。

### 5.7 保存后

- 保存成功提示「规则已保存」。
- 显示「下一次校验生效」。
- 若规则放宽，显示「已移出的频道需要重新同步源才能恢复」。
- 若周期变化，立即刷新「下次运行」。

## 6 结果

### 6.1 筛选

- 来源：全部 / 单个同步源。
- 分组：全部 / 单个分组。
- 状态：全部 / 已准入 / 已移出 / 已下线 / 已保留 / 暂停准入 / 暂停移出 / 源已移除。
- 原因：全部 / 合格 / 不可达 / 速率低 / 分辨率不符 / 延迟高 / 探测错误。
- 搜索：频道名、频道 id。
- 「刷新」按钮。

### 6.2 表格

| 列 | 内容 |
| --- | --- |
| 频道 | 名称 + `[id]` |
| 来源 | 源名称；手工频道显示「手工」 |
| 目标分组 | 分组名 |
| 动作 | 准入 / 移出 / 下线 / 保留 / 暂停 |
| 原因 | 中文原因徽章 |
| 延迟 | `120 ms`，无值显示 `—` |
| 速率 | `2.4 MiB/s`，无值显示 `—` |
| 分辨率 | `1080p`，无值显示 `—` |
| 最近校验 | 相对时间，悬停显示绝对时间 |
| 操作 | 详情；已准入频道显示「重新校验」 |

分页：50 / 100 / 200，默认 100。显示总数。

### 6.3 行状态

- 已移出：红色「已移出」徽章。行只读，不提供「重新校验」。
- 已下线：黄色「已下线」徽章。频道仍在分组。
- 探测错误：灰色「探测错误」。不触发移出。
- 安全阀暂停：黄色「已暂停」徽章。合格未准入写「暂停准入」，失败未移出写「暂停移出」。
- 源已不再提供：灰色「源已移除」徽章。
- 结果超过保留期：不显示。

### 6.4 详情抽屉

显示：

- 频道、来源、目标分组。
- 动作、原因、最近校验、首次失败时间。
- 延迟、速率、分辨率、HTTP 状态。
- 探测档位、规则快照（最低速率、最大延迟、分辨率上下限）。
- 地址哈希，不显示完整地址。
- 已移出时提示：「需要重新同步源才能再次准入。」

### 6.5 运行联动

- 任务运行时表格每 2 秒刷新。
- 任务完成后停止轮询，显示「本轮新增移出 N 个」。
- 空结果按原因显示：未运行 / 无匹配 / 没有结果记录。

## 7 来源

### 7.1 列表

只列 `mode=sync` 的源。聚合源在下方折叠区显示「聚合源不参与准入」。

| 列 | 内容 |
| --- | --- |
| 来源 | 名称 + id |
| 状态 | 已启用 / 已停用 |
| 门控 | 开关 |
| 最近同步 | 状态、时间、阶段 |
| 准入 | 当前准入频道数 |
| 最近移出 | 最近一轮移出数 |
| 失败率 | 最近一轮移出数 / 判定数 |
| 操作 | 立即同步 / 停用 / 编辑 / 删除 |

同步中显示阶段：

```
抓取清单 → 解析 → 地址变更校验 → 新候选 120/500 → 写入分组
```

被截断时显示：

```
本轮准入 120，剩余 380 个候选下一轮继续
```

### 7.2 关闭门控

点击开关关闭时确认：

```
关闭后，新频道不再校验，已准入频道不再周期移出。
频道由同步直接管理。
[关闭门控] [取消]
```

开启时无需确认。

### 7.3 停用源

停用必须选择频道处理：

```
停用源「源 A」
停用后停止同步，并暂停该源的质量校验。

已准入频道：
  (•) 保留在分组（推荐）
  ( ) 同时移出分组

[ ] 记住我的选择（只记住保留）

[停用] [取消]
```

选择「同时移出」后二次确认：

```
将移出 120 个频道。移出后不会自动恢复。
[确认移出] [取消]
```

### 7.4 删除源

```
删除源「源 A」
删除后无法恢复源配置。

已准入频道：
  (•) 保留为本地频道（推荐）
  ( ) 随源删除

[ ] 保留最近 7 天的结果记录

[删除] [取消]
```

选择「随源删除」后二次确认，列出频道数。

删除后：

- 保留：频道清除来源 id，`sync_follow=false`，按手工策略处理。
- 删除：频道从分组移除，结果记录保留到保留期。

## 8 同步与校验流程

### 8.1 首次同步

1. 管理员保存 `mode=sync` 源。
2. 源卡片显示「同步中」。
3. 抓取与解析。失败则结束，成员不变。
4. 生成候选计划。
5. 先校验 URL 变化的已准入频道。失败则移除；`probe_error` 则暂停本轮。
6. 再校验新候选。显示「新候选 x/y」。合格写入分组；不合格只写结果记录。
7. 已准入且未变化的频道不重复校验，由周期校验负责移出。
8. 时间或预算截断时，已处理结果照常应用，剩余新候选下一轮继续。
9. 安全阀触发时，暂停全部成员变更。
10. 结果显示「本次准入 N，未准入 M，剩余 K」。

### 8.2 周期校验

1. cron 或小时周期触发。
2. 校验已准入频道，包括同步门控未重复校验的频道。
3. 不合格频道立即移出分组。
4. 结果页与分组页更新。
5. 安全阀触发时，本轮不移出，结果动作写「暂停移出」。

### 8.3 手动校验

- 概览「立即校验全部」：校验全部已准入频道。
- 结果页行「重新校验」：只校验一个已准入频道。确认提示「失败会立即移出分组」。
- 分组页频道「校验」：只校验一个已准入频道。确认提示同上。
- 停用状态：只测量，不改变成员。
- 任务冲突：提示「已有校验任务在运行」。

### 8.4 规则变更

- 保存后不自动重跑。
- 下一次周期或手动校验使用新规则。
- 放宽规则不会自动恢复已移出频道。页面提示重新同步源。

### 8.5 恢复

- 已移出频道不自动复检。
- 下一次源同步重新校验。
- 源已不提供该频道时，成员不恢复。

## 9 分组页与设置页

### 9.1 分组页

- 分组标题保留质量统计：`准入 12 · 最近校验 12:30`。
- 频道行显示延迟、速率、分辨率、结果徽章。
- 点击徽章进入质量结果页，按该频道过滤。
- 手工频道显示失败处理：`失败保留` 或 `失败下线`。
- 频道编辑弹窗增加：
  - 手工频道：失败处理（继承 / 保留 / 下线）。
  - 同步频道：只读说明「由源门控管理，失败立即移出」。

### 9.2 设置页

- 删除「可用性校验」卡片中的全部质量字段。
- 增加一张只读卡片：

```
质量校验
已启用 · 每 6 小时
[打开质量校验]
```

## 10 文案

| 场景 | 文案 |
| --- | --- |
| 保存成功 | 规则已保存，下一次校验生效 |
| 规则放宽 | 已移出的频道需要重新同步源才能恢复 |
| 运行冲突 | 已有校验任务在运行 |
| 取消 | 取消中，已完成的结果保留 |
| 安全阀 | 批量失败，已暂停本轮成员变更 |
| 源停用保留 | 源已停用，频道保留在分组 |
| 源停用移出 | 源已停用，频道已移出分组 |
| 源删除保留 | 源已删除，频道转为本地频道 |
| 源删除移出 | 源已删除，频道已移出分组 |
| 已移出结果 | 需要重新同步源才能再次准入 |
| 部分准入 | 本轮准入 N，剩余 M 个候选下一轮继续 |
| 暂停准入 | 安全阀触发，合格候选本轮未准入 |
| 暂停移出 | 安全阀触发，不合格频道本轮未移出 |
| 地址未验证 | 地址变更校验失败，本轮同步已暂停 |
| 质量关闭运行 | 质量校验已停用，本次只测量 |

## 11 校验与权限

- 所有质量页与写操作仅管理员。
- 分辨率格式：`数字x数字`，留空允许。
- 最低分辨率不得高于最高分辨率。
- 比例范围 1–100。
- 最小移出数量 1–100000。
- 周期 1–8760 小时。
- cron 必须 5 段。
- 规则保存必须带 `revision`。
- 源停用移出、源删除移出必须二次确认。

## 12 验收标准

1. 管理员侧栏出现「质量校验」，普通用户看不到。
2. 系统设置不再编辑质量字段，只显示入口。
3. 规则可以保存；revision 冲突时提示重新加载。
4. cron 非法时不能保存，合法时显示下次运行。
5. 周期模式支持按小时与 cron，互不覆盖。
6. 首次同步只把合格频道写入分组。
7. 已准入频道失败后立即从分组消失。
8. 已准入且未变化的频道不在同步门控重复探测，由周期校验移出。
9. 同步门控截断时，已准入频道不被误删；剩余新候选下一轮继续。
10. 移出频道在结果页有原因、指标、时间与动作。
11. 已移出频道不自动复检，结果页明确提示。
12. 下一次同步重新准入恢复的频道。
13. 手工频道默认失败保留；选择下线后只从订阅隐藏。
14. 安全阀默认开启；触发时本轮不改变成员并告警。
15. 源抓取失败、`probe_error` 不改变成员。
16. 停用源时可选择保留或移出频道。
17. 删除源时可选择保留为本地或随源删除。
18. 全局关闭时手动校验只测量，不改变成员。
19. 关闭单源门控后该源不参与准入与周期移出。
20. 结果筛选、分页、详情可用。
21. 分组页徽章可跳到对应结果。
22. 源同步与质量任务不会并发修改配置。
23. 重启后手工频道下线状态保留。

## 13 验收环境与场景

### 13.1 环境

- 构建：`tests/manual/local/docker-compose.yml` 的 `local-test` 目标。
- 运行：Alpine + OpenRC，容器 `tvb-local`，端口 `19900`，限制 `1 vCPU / 128 MB`。
- 模拟源：主机 Python HTTP 服务，监听 `0.0.0.0:19932`。容器通过 `host.docker.internal:19932` 访问。
- 后续脚本：`scripts/smoke-quality-admission.sh`。

模拟端点：

| 端点 | 行为 |
| --- | --- |
| `/ok.m3u8` | 正常媒体清单，切片快速返回。 |
| `/slow.m3u8` | 切片每 100 ms 发送 1 KiB，速率低于阈值。 |
| `/dead.m3u8` | 返回 404。 |
| `/source.m3u8` | 源清单，包含正常、慢速、不可达三个频道。 |
| `/control?slow=ok` | 把慢速频道切到正常地址，用于恢复测试。 |
| `/control?slow=slow` | 切回慢速地址。 |

测试规则：

- `probe_mode=speed`
- `min_speed_mib=1.0`
- `sample_secs=2`
- `sample_segments=2`
- 安全阀测试时设 `min_remove_count=2`、`max_remove_ratio=0.5`
- cron 测试使用 `* * * * *`

### 13.2 场景

1. **首次准入**：同步 `/source.m3u8`。分组只出现正常频道；慢速与 404 只在结果页出现。
2. **立即移出**：先关闭门控同步三个频道，再开启门控并执行校验。慢速与 404 立即从分组消失。
3. **同步恢复**：切换 `/control?slow=ok`，重新同步。慢速频道重新进入原分组。
4. **安全阀**：让 2 个频道失败，阈值设为 2 个 / 50%。本轮不改变成员，页面显示暂停警告。关闭安全阀后重跑，失败频道被移出。
5. **cron**：设置 `* * * * *`，等待一次自动运行。检查任务时间与结果。
6. **按小时**：设置 1 小时，检查状态接口显示下次运行时间，不等待实际触发。
7. **源停用**：选择保留，频道仍在分组，质量校验暂停。选择移出，频道消失。
8. **源删除**：选择保留为本地，频道 `source_id` 清空。选择随源删除，频道消失，结果记录仍可查。
9. **部分准入**：把门控时限设为很短，确认已准入频道不减少，剩余新候选在下一轮继续。
10. **低配**：运行期间容器内存低于 128 MB，服务不重启，健康检查保持 200。

### 13.3 通过标准

- 脚本输出 `smoke-quality-admission: PASS`。
- 分组、订阅、结果页三处状态一致。
- 每个移出频道都有结果记录与原因。
- 源抓取失败时成员不变。
- 容器日志无 panic、无 OOM。
