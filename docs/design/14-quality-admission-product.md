# 14 · 订阅源质量准入产品设计

> 阶段：产品设计。本文只定义产品行为，不定义接口、表结构与代码。
> 后续文档：功能设计 → 系统设计 → 代码实现计划。
> 相关旧方案：[`13-availability-and-speedtest.md`](13-availability-and-speedtest.md)。

## 1 背景

订阅源会带来大量不可用或低质量频道。当前做法是先把频道全部同步进分组，再靠订阅过滤隐藏。问题有三个：

- 分组管理里混入大量失败频道，管理成本高。
- 规则入口分散在系统设置与分组页，难找。
- 失败频道只在订阅里消失，管理员难以解释原因。

本设计把同步改为“质量准入”：只有通过规则的频道才进入分组管理。已准入频道不合格时立即移出。产品只保留准入与结果，不保留淘汰池，也不自动复检已移出频道。

## 2 目标与非目标

### 2.1 目标

- 同步源频道必须通过质量规则，才进入分组管理。
- 已准入的同步频道一旦不合格，立即移出分组。
- 提供独立的质量规则页面，集中管理规则、结果与来源状态。
- 每次判定都有可查看的结果与原因。
- 校验周期支持 cron 与按小时周期。

### 2.2 非目标

- 不管理聚合源。聚合源不进入分组，保持现有渲染逻辑。
- 不阻止直接播放。质量准入只管理配置成员。
- 不做按用户的质量规则。
- 不做分布式探测。
- 不做淘汰池、自动复检、自动恢复。
- `ffprobe` 只用于分辨率识别。不做广告过滤、同组去重。

## 3 用户与场景

### 3.1 管理员添加托管源

管理员添加 `mode=sync` 的订阅源。系统抓取清单，逐个校验频道。合格频道进入分组。不合格频道不进入分组，只在结果页保留最近一次判定。

### 3.2 日常周期校验

系统按 cron 或小时周期校验已准入频道。某个频道失败后立即移出分组，订阅清单同步消失。结果页显示原因与时间。

### 3.3 管理员调整规则

管理员在质量页调低最低速率。下一次校验后，不合格频道被移出。若调高阈值，已移出的频道不会自动回来；需要重新同步源，由同步门控重新准入。

### 3.4 手工频道

手工频道默认不自动移出。管理员可选择：

- `keep`：失败也保留在分组与订阅。
- `hide`：保留在分组，失败时从订阅下线，恢复后自动显示。
- 不提供 `remove`。没有淘汰池时，移出等于永久删除，风险过高。

## 4 核心概念

| 概念 | 定义 |
| --- | --- |
| 同步源 | `[[playlist.sources]]` 中 `mode=sync` 的源。 |
| 候选频道 | 本次源清单中，准备进入分组的频道。 |
| 判定 | 按有效规则探测并得出结论。 |
| 准入 | 判定合格，写入 `config.groups`。 |
| 移出 | 判定不合格，从 `config.groups` 删除。 |
| 下线 | 保留在 `config.groups`，但不进入订阅清单。 |
| 结果记录 | 最近一次判定的快照，供面板查看。不是重试池。 |

“移出”与“下线”必须分开显示，避免管理员误以为频道还在分组里。

## 5 产品规则

### 5.1 适用范围

- 只对 `mode=sync` 的源频道执行准入与移出。
- 手工频道执行 rules 判定，但失败处理按频道策略执行。
- 聚合源不参与准入，也不产生分组。
- 归档组不校验。
- 每个同步源可关闭门控。关闭后该源不参与准入与周期移出，频道由同步直接管理。
- 全局质量校验关闭时，不执行任何成员变更。手动校验只测量与记录。

### 5.2 判定时机

- 源同步：抓取、解析后，校验新候选与 URL 变化的已准入频道。未变化的已准入频道不重复校验，由周期校验负责。
- 周期校验：按 cron 或小时周期校验当前已准入频道。失败即移出。
- 手动校验：管理员可对全部、单源、单分组、单频道发起。
- 同一时间只允许一个校验任务。新任务与运行中的任务冲突时返回忙碌。
- 新候选较多时按预算分轮准入。未处理候选留到下一轮，页面显示剩余数量。

### 5.3 失败处理

| 对象 | 失败后的处理 |
| --- | --- |
| 同步源候选频道 | 不进入本次计划。 |
| 已准入同步频道 | 立即移出分组。 |
| 手工频道 `keep` | 保留在分组与订阅。 |
| 手工频道 `hide` | 保留在分组；连续失败超过宽限后从订阅下线，恢复后立即显示。 |
| 手工频道 | 不提供 `remove`。 |
| 源抓取或解析失败 | 不改变任何频道成员。 |
| `probe_error`（新候选） | 不准入。记录结果，下一轮重试。 |
| `probe_error`（地址变化） | 暂停本轮同步，保留原频道与原地址。 |
| 地址变化 | 按新地址判定；失败时移出，合格时更新地址。 |

### 5.4 安全阀

安全阀默认开启。

触发条件同时满足：

- 本轮将移出的同步频道数不少于 `min_remove_count`。
- 将移出数占本轮完成判定的同步频道数比例不低于 `max_remove_ratio`。

默认值：

- `max_remove_ratio = 0.5`
- `min_remove_count = 10`

例子：

- 200 个频道，150 个将移出：比例 75%，数量 150，触发。
- 200 个频道，12 个将移出：比例 6%，不触发。
- 20 个频道，8 个将移出：比例 40%，不触发。
- 3 个频道，2 个将移出：比例 67%，但数量 2 小于 10，不触发。小源不会因一两个频道误触发。

触发后，本轮不执行任何成员变更：

- 已准入频道保留。
- 候选频道不新准入。
- 结果页显示“批量失败，已暂停成员变更”。
- 管理员修正规则、调整阈值或关闭安全阀后重新执行。

统计分母只算本轮完成判定的同步频道。`probe_error`、未知、源抓取失败不计入移出，也不触发安全阀。

小源自适应：可移出频道少于 3 个时，数量阈值保持 `min_remove_count`。3 个及以上且全部可移出频道都失败时，数量阈值取 `min_remove_count` 与「可移出频道数 × 30%（向上取整）」的较小值。部分失败仍按原阈值，避免误暂停。

### 5.5 恢复

- 已移出的同步频道不自动复检。
- 下一次源同步会把它们当新候选重新校验。频道仍在源中且合格时，重新进入原分组。
- 新候选按分轮准入。已移出频道可能不在本轮游标范围内，需要等待后续同步。
- 源不再提供该频道时，不保留成员，也不保留准入状态。
- 手工频道没有 `remove`，不存在自动恢复问题。
- 结果页提示：“已移出频道需要重新同步源才能恢复。”

### 5.6 结果记录

每次判定保存一条结果记录：

- 来源、分组目标、频道稳定键、名称、地址哈希。
- 判定结果、原因、延迟、速率、分辨率。
- 最近校验时间、执行动作（准入、移出、下线、保留、暂停准入、暂停移出、源已移除）。
- 规则版本或规则哈希。
- 源不再提供频道时也写记录，避免“频道消失但没有原因”。

结果记录不是淘汰池：

- 不参与调度。
- 不自动重试。
- 不自动恢复。
- 只用于面板展示与排障。
- 按保留期清理，默认 7 天。`0` 表示不自动清理。

保留期解决三个问题：

- 频道被移出后仍能解释原因。没有记录时，分组里只剩下“消失了”。
- 调整规则后能对比失败原因，区分规则过严、源故障与探测错误。
- 能回答“什么时候移出的、当时速率和分辨率是多少、用的哪版规则”。

记录按频道稳定键保留最近一条，不按每轮追加历史。已准入频道的记录随校验更新。已移出频道超过保留期后删除。源被删除且用户选择删除频道时，记录仍按保留期保留。

### 5.7 源停用与删除

停用与删除必须让管理员选择已准入频道的处理方式。

停用源：

- 默认：保留频道，停止同步，暂停该源的质量校验。
- 可选：同时移出该源的全部已准入频道。
- 停用可恢复。保留的频道在重新启用后继续参与同步与校验。

删除源：

- 默认：保留频道，断开来源关系，转为本地频道。
- 可选：随源删除全部已准入频道，并保留结果记录到保留期结束。
- 删除不可恢复。选择“随源删除”时必须二次确认。

选择“保留频道”时的行为：

- 源 id 从频道上清除。
- `sync_follow` 设为 `false`。
- 频道按手工频道策略处理：默认 `keep`，可改为 `hide`。

选择“移出频道”时的行为：

- 从 `config.groups` 删除频道。
- 不进入淘汰池，不自动恢复。
- 结果记录保留到保留期结束。

### 5.8 周期

质量校验支持两种模式：

- `cron`：5 段表达式，按服务器时区。
- `interval`：按小时周期，最小 1 小时。

页面显示下一次运行时间。旧的秒级周期只作为迁移输入，不再展示。

### 5.9 规则

- 全局规则是默认值。
- 源、分组、频道可覆盖。
- 页面必须显示有效值与来源层级。
- 支持按分辨率设置最低速率：取不超过实际分辨率的最高档；未命中时用全局最低速率。
- 同一规则同时用于同步门控、周期校验与手动校验，避免三套判定。

### 5.10 手工频道与现有下线开关

现有 `offline_on_fail` 继续表示“失败后从订阅下线”，不表示移出。

映射：

- 手工频道默认 `keep`。
- `offline_on_fail=true` 映射为 `hide`，默认宽限 1800 秒。首次失败只记录起点，超过宽限后仍失败才下线；恢复合格立即清除下线状态。
- 同步频道默认 `remove`。
- 不再新增手工频道 `remove` 入口。

## 6 页面

侧栏新增「质量校验」。系统设置中的质量卡片移除，只保留入口链接。

### 6.1 概览

- 总开关与运行状态。
- 周期模式、下一次运行时间。
- 最近一次任务：时间、耗时、下载量、准入数、移出数。
- 合格与移出数量。
- 「立即校验全部」「取消」。

### 6.2 规则

- 全局阈值、动作、预算、并发、安全阀。
- 周期模式：cron 或小时。
- 源、分组、频道覆盖列表。
- 每个字段显示有效值与来源（全局 / 源 / 分组 / 频道）。

### 6.3 结果

- 筛选：来源、分组、结果状态、原因。
- 列：频道、来源、目标分组、延迟、速率、分辨率、原因、最近校验、动作。
- 已移出频道加「已移出」徽章与原因。
- 单频道「重新校验」按钮。已移出频道提示需要重新同步源。

### 6.4 来源

- 每个同步源：门控开关、最近同步、准入数、移出数、失败率、最近门控时间。
- 聚合源只显示抓取状态，不显示准入统计。

## 7 缓存与复用

- 不使用跨轮测量结果缓存。跨轮复用会掩盖恢复与新增失败。
- 同一轮校验内，相同 URL 只测一次。
- 按 Host 共享测量结果默认关闭，可在规则页开启。
- 结果记录用于展示，不用于跳过下一轮判定。

## 8 成功标准

- 同步完成后，分组中不存在未通过规则的同步源频道。
- 已准入频道失败后，下一份订阅不再包含它。
- 每个被移出的同步频道都有结果记录与原因。
- 源抓取失败时，成员不发生任何变化。
- cron 与小时周期都能按配置触发。
- 管理员能在独立页面完成规则、结果与来源管理。

## 9 决策记录

| 编号 | 决策 | 结论 | 理由 |
| --- | --- | --- | --- |
| D1 | 准入粒度 | 逐频道 | 满足“合格才进入分组”。 |
| D2 | 已准入失败 | 立即移出 | 用户确认。规则全局稳定，抖动风险可接受。 |
| D3 | 淘汰池 | 不做 | 用户确认。不做复检与自动恢复。 |
| D4 | 已移出恢复 | 下一次源同步 | 没有淘汰池时的唯一恢复路径。 |
| D5 | 手工频道 | `keep` / `hide`，下线带宽限 | 无淘汰池时 `remove` 不可逆，不提供。手工频道由管理员维护，宽限避免单次抖动下线。 |
| D6 | 安全阀 | 默认开启，比例 50%，最小 10 个；小源按 30% 自适应 | 用户确认。触发时暂停本轮成员变更。 |
| D7 | 周期 | cron 或小时 | 用户要求。复用现有 cron 解析。 |
| D8 | 规则入口 | 独立页面 | 现有入口分散，用户要求集中管理。 |
| D9 | 结果记录 | 保留最近一条，默认 7 天 | 支持查看结果与排障，不引入淘汰池。 |
| D10 | 跨轮测量缓存 | 不使用 | 会掩盖恢复与新增失败。 |
| D11 | 源停用或删除 | 保留频道为默认，提供移出选项 | 用户要求选择。停用可恢复；删除时移出需二次确认。 |
| D12 | DASH 地址变化 | 只做连通检查 | 清单与测速档不支持 DASH。永久暂停会阻塞整个源；HTTP 检查可验证新地址在线性。 |
| D13 | 探测档位 | 规则可自动提升实际档位 | 界面显示配置档位与实际档位，避免“选了连通但按测速执行”的误解。 |

## 10 默认值

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 结果记录保留期 | 7 天 | `0` 表示不自动清理。 |
| 安全阀 | 开启 | 可关闭。 |
| `max_remove_ratio` | 0.5 | 将移出数占完成判定数的比例。 |
| `min_remove_count` | 10 | 小于该数量不触发，保护小源。 |
| 源停用 | 保留频道 | 停止同步并暂停校验；可改选移出。 |
| 源删除 | 保留为本地频道 | 清除来源关系；可改选随源删除，需二次确认。 |
