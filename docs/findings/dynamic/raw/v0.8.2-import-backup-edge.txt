## D24-F. include / exclude (per-source 与 global_exclude)
################################################################################

include/exclude 匹配 **频道名** (不区分大小写, 子串); 支持前缀语法:
  group:<名> / id:<tvg-id> / /正则/  —— 在 **per-source include 与 exclude 均有效**
  (与 spec S-SUB-07「仅全局排除支持」不一致, 见发现文档)

$ include ["CCTV"]                     -> kept=2 (CCTV-1/2)
$ include ["cctv"]                     -> kept=2 (大小写不敏感)
$ include ["电影"]                     -> kept=2 (游戏名子串匹配 电影-动作/电影-喜剧)
$ include ["group:央视"]               -> kept=2
$ include ["group:央"]                 -> kept=2 (group: 亦为子串匹配)
$ include ["id:mov.1"]                 -> kept=1 (电影-动作)
$ include ["/电影/"]                   -> kept=2 (正则)
$ include ["央视","CCTV"]              -> kept=2 (多词 OR)
$ exclude ["CCTV-2"]                   -> kept=6
$ exclude ["id:mov.2"]                 -> kept=6
$ exclude ["/CCTV-./"]                 -> kept=5
$ exclude ["group:电影"]               -> kept=5

global_exclude (config.playlist.global_exclude, 值同语法) 全源生效:
$ global_exclude ["购物"]        -> 上游条目 7->6 (去 购物频道1)
$ global_exclude ["group:电影"]  -> 7->5
$ global_exclude ["id:sh.drag"]  -> 7->6
$ global_exclude ["/CCTV-./"]    -> 7->5

# 管道顺序 (trace 字段): total -> after_group -> after_global_exclude -> after_include -> after_exclude

# 启动日志 (off):
10-18 19:07:56  INFO 【启动】边缘来源校验模式: Off(拒绝非边缘来源=true)
# 启动日志 (cloudflare):
10-18 19:19:03  INFO 【启动】边缘来源校验模式: Cloudflare(拒绝非边缘来源=true)

# 二进制字符串 (samples/v0.8.2/unpacked/iptv-proxy-arm64):
#   server.edge_mode = "off":转发头(X-Forwarded-For / CF-Connecting-IP)可被任意伪造,…
#   套了 Cloudflare 请设 edge_mode = "cloudflare" 并配 edge_secret;自建反代请设 edge_mode = "proxy" 并把反代出口 IP 写进 trust_proxy。
#   【安全】edge_mode = "proxy" 但 trust_proxy 为空:没有任何对端会被判为可信,所有管控将退回按 TCP 源 IP 记账。
#   需要**复制到两处、保持一致**:(a) config.toml 的 server.edge_secret;
#     (b) Cloudflare → Rules → Transform Rules → Modify Request Header → Set static,
#         Header name 填 X-IPP-Edge-Secret,Value 填同一个值。建议先设 edge_reject = false 观察日志,…
#   【安全】拒绝非边缘来源的请求: peer=… path=…
#   【边缘·观察模式】过去一段时间有 N 次来源不可信的请求(edge_reject=false,已放行)。最近一次: peer=… path=…
#   【边缘】已更新 Cloudflare IP 段(N 条)
#   【边缘】更新 Cloudflare IP 段失败(…),保留现有列表
#   【边缘】拉到的 Cloudflare IP 段为空,保留现有列表  (+ 内嵌默认 CF 段列表, v4/v6)
#   URL: https://www.cloudflare.com/ips-v4 , https://www.cloudflare.com/ips-v6
#   探测头名: x-ipp-edge-secret / X-IPP-Edge-Secret (另见 x-forwarded-for, x-real-ip)

# edge_mode 取值: off / cloudflare / proxy

# ---- 实验 1: mode=cloudflare, edge_reject=false (观察模式) ----

# ---- 实验 2: mode=cloudflare, edge_reject=true ----

probe (GET /playlist.m3u):
  none                                        : 200
  secret-correct (X-IPP-Edge-Secret)          : 200
  secret-wrong                                : 200
  xff-public     (X-Forwarded-For: 1.2.3.4)   : 403   text/plain "Forbidden"
  realip-public  (X-Real-IP: 1.2.3.4)         : 403

# 判定模型 (实测): 请求**带转发头** (X-Forwarded-For / X-Real-IP / CF-Connecting-IP) 时进入边缘校验;
#   仅当 X-IPP-Edge-Secret 等于 edge_secret 才放行, 否则 403。**无转发头**的直连请求一律放行。
#   edge_secret 值本身不用于"认来源", 只作为是否经过边缘(CF Transform Rule)的凭据。
#   CF 网段命中与否不改变结论 (cfip-CFrange only 仍 403)。
