体缺失 → {"error":"Failed to deserialize the JSON body … items[0]: missing field `ext`"}   # 每项要 name/ext/data

->
{"ok":true,"failed":[],
 "added":[{"anim_fixed":null,"animated":false,"bytes":168,"file":"C1.png","name":"C1","url":"/logo/C1.png"},

### POST /panel/api/logo/suggest {"hint":"C1"}
{"suggestions":[{"channel":"C1","cid":"c1","gid":"test1","group":"test1","has_logo":false,"logo_name":"C1","score":100},
                {"channel":"C1x","cid":"c1","gid":"g2","group":"g2","has_logo":false,"logo_name":"C1x","score":80}]}
# score：精确=100、前缀=80

### POST /panel/api/logo/animate
{"file":"C1.png","effect":"diagonal","quality":80}
 -> {"error":"… quality: invalid type: integer `80`, expected a string"}    # quality 必须是字符串
{"file":"ZZnomatch.png","effect":"spot","quality":"80"}
 -> {"ok":true,"file":"ZZnomatch.png","frames":10,"width":64,"height":64,"total_ms":2220,
     "bytes_before":176,"bytes_after":2752,"dirty_ratio":20.0}
磁盘：cache/logos/ZZnomatch.png（2752B，文件覆盖）+ cache/logos/.orig/ZZnomatch.png（176B 原图备份）
list：has_original=True；animated 仍 False（判定语义未定）
effect 选项（面板）：diagonal 斜向扫光 / vertical 竖向扫光 / bounce 来回扫光 / spot 光点掠过 / glow 边缘辉光 / breathe 呼吸明暗
GET /logo/ZZnomatch.png -> 200 image/png

### POST /panel/api/logo/restore {"file":"<f>"}
有备份 -> {"ok":true}（还原静态原图）
无备份 -> {"error":"没有找到原图备份"}

### POST /panel/api/logo/rename {"file":"C1.png","new_name":"C1 HD"}
-> {"ok":true,"file":"C1 HD.png","url":"/logo/C1%20HD.png","updated_channels":2}
清单 → tvg-logo="http://127.0.0.1:19899/logo/C1%20HD.png"   # 频道引用随改名更新

### POST /panel/api/logo/delete {"file":"C1 HD.png","clear_refs":true}
-> {"ok":true,"removed":1,"cleared_channels":2,"errors":[]}
清单 → tvg-logo=""    # clear_refs=true 时清空引用
{"file":"ZZnomatch.png","clear_refs":false} -> {"ok":true,"removed":1,"cleared_channels":0,"errors":[]}
