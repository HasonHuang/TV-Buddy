->

旧 token 播放 GET /g2/c1.m3u8?token=135a…189f -> 200   （宽限期仍有效）
新 token 播放 GET /g2/c1.m3u8?token=edcc…ab7a -> 200
轮换后 GET /panel/api/security/token ->
{"current_value":"edcc62abcd32a7991ae0b14c6068b3ca4584be8bd3d6ab7a","enabled":true,
 "status":{"current":{"remaining_secs":86398,"valid":true,"value":"edcc****ab7a"},

 "ttl_hours":24}
=> 旧 token 宽限 3598s ≈ 3600s（1 小时）

### IP 封禁/解封
POST /panel/api/security/ip/ban   {"ip":"203.0.113.7"}
 -> {"error":"Missing ips array"}            # 字段名是 ips（数组）
POST /panel/api/security/ip/ban   {"ips":["203.0.113.7","203.0.113.8"]}
 -> {"ok":true,"results":[{"ip":"203.0.113.7","ok":true},{"ip":"203.0.113.8","ok":true}],"secs":2592000}
GET /panel/api/security/ip/stats
 -> {"unique_ips":2,"active_sessions":0,
     "banned_ips":[{"ip":"203.0.113.7","remaining_secs":2591999},
                   {"ip":"203.0.113.8","remaining_secs":2591999}]}
POST /panel/api/security/ip/unban {"ips":["203.0.113.7"]}
 -> {"error":"Missing ip"}                    # 解封字段是单数 ip
POST /panel/api/security/ip/unban {"ip":"203.0.113.7"} -> {"ip":"203.0.113.7","ok":true}
POST /panel/api/security/ip/unban {"ip":"203.0.113.8"} -> {"ip":"203.0.113.8","ok":true}
GET /panel/api/security/ip/stats -> {"unique_ips":2,"active_sessions":0,"banned_ips":[]}
（面板另有 POST /panel/api/security/ip/unban-batch）
