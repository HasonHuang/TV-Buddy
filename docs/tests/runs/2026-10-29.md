# P3-6 逐屏视觉对拍记录（2026-10-29）

> 写作风格：ASD-STE100 简化技术写作。一句一个意思。主动语态。用简单现在时。

## 1. 目的

本文档记录 13 个一级分区与登录页的视觉对拍结果。

判据是**元素存在、顺序、层级与版式**。判据不是像素一致。

参考图见 `docs/design/reference/img/`。参考图只用来对照布局。文字与品牌不对照。

对应进度项：P3-6、V-10。

## 2. 方法

1. 用本地构建的二进制起独立实例。端口 `19898`。配置与数据全部落在 `/tmp/tv-buddy-panel-test/`。
2. 起本地伪上游。端口 `9999`。
3. 导入 4 个分组、5 个频道。覆盖 `proxy`、`dash`、`passthrough`、空组、故障频道。
4. 用 Chrome 156 在无头模式下打开 `/panel`。视图 1440×1000，设备像素比 1。
5. 逐屏点击 13 个导航项。每屏截视口图与整页图。
6. 把参考图与本实现图横向拼接。左为参考，右为本实现。逐屏比对。

复现命令见附录 A。

## 3. 总体结论

| 项 | 结果 |
| --- | --- |
| 分区数 | 13。全部可达 |
| 页头骨架 | 13/13 一致。图标、标题、副标题、右侧操作的位置相同 |
| 侧栏 | 一致。13 项、顺序、选中态、宽度均相同 |
| 版式栅格 | **不一致**。参考用双列或 2×2，本实现用单列或三列 |
| 功能入口 | 4 项缺失，见 §5 |
| 装饰元素 | 页脚、图标、背景纹理不一致，见 §6 |

本实现与目标的差异**主要在版式**，不在功能面。功能面只有 4 项真缺口。

## 5. 功能缺口（4 项）

| ID | 项 | 现状 | 影响 |
| --- | --- | --- | --- |
| VG-1 | 分组卡折叠 | 无折叠代码。分组多时只能滚动 | 分组多时难定位 |
| VG-2 | 台标批量动画与还原 | 只有单个动画与还原接口。无「一键全部」入口。上传无拖放区与转换参数 | 批量处理台标要逐个点 |
| VG-3 | 素材页「配置中检测到的视频 URL」 | 无此卡。后端无对应扫描接口 | 配置里的 404 跳转等 URL 需要手工发现并转换 |
| VG-4 | 频道热度排行维度 | 本实现按分组排请求数。目标按频道在线人数排 | 想看单个频道的热度时做不到。`/panel/api/stats` 需补频道维度 |

## 6. 装饰与版式差异（不判为缺口）

| 项 | 参考 | 本实现 | 处理 |
| --- | --- | --- | --- |
| 页脚 | `© 2026 YanG · GitHub` | 无 | **不补**。品牌信息属目标派生内容，按数据纪律不复制 |
| 侧栏品牌 | `IPTV Proxy` + 已运行时长 | `TV Buddy` + 管理面板 | 保持。品牌自研 |
| 登录背景 | 网格纹理 | 纯色 | 可选。无功能影响 |
| 统计卡图标 | 有 | 无 | 可选 |
| 日志区配色 | 深色终端 | 白底 | 可选。可读性相当 |
| 栅格列数 | 双列 / 2×2 | 单列 / 三列 | 可选。信息量相同，只是排布不同 |

## 7. 结论

P3-6 完成。面板与目标在**页头骨架、侧栏、13 个分区可达性**上一致。

差异分三类：

1. 功能缺口 4 项（VG-1 至 VG-4）。排入后续。
2. 版式差异。信息量相同。是否对齐由项目负责人决定。
3. 装饰差异。页脚与品牌不补。

## 附录 A · 复现

```bash
# 1. 构建
cd frontend && pnpm build && cd ..
cargo build --offline

# 2. 起实例
mkdir -p /tmp/tv-buddy-panel-test/cache
cat > /tmp/tv-buddy-panel-test/config.toml <<'EOF'
[server]
bind = "127.0.0.1:19898"
[health]
interval_secs = 10
[cache]
disk_path = "/tmp/tv-buddy-panel-test/cache"
EOF
./target/debug/tv-buddy /tmp/tv-buddy-panel-test/config.toml >/tmp/tv-buddy-panel-test/run.log 2>&1 &

# 3. 伪上游
mkdir -p /tmp/tv-buddy-origin && cd /tmp/tv-buddy-origin
printf '#EXTM3U\n#EXT-X-VERSION:3\n#EXT-X-TARGETDURATION:4\n#EXTINF:4.0,\nseg1.ts\n#EXT-X-ENDLIST\n' > live.m3u8
printf 'x' > seg1.ts
python3 -m http.server 9999 &

# 4. 截图（脚本见 scripts/panel-shots.js）
node scripts/panel-shots.js /tmp/p3-6-shot
```

数据与首页一致：4 个分组、5 个频道。见 `docs/tests/02-panel-acceptance.md` §2.3。
